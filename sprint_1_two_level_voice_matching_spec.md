# Sprint Spec 1 v3 — Production Two-Level Voice Matching

## 0. Status

This spec supersedes the earlier MVP-style version. It is intended for production implementation.

Main corrections from earlier draft:

```text
1. Fix timestamp offset rule:
   - Whisper on master audio = global timestamps, do NOT add beat.voice_in.
   - Whisper per beat = local timestamps, DO add beat.voice_in.

2. pause_after_sec is not generated by TTS.
   - TTS produces spoken beat audio only.
   - The pipeline synthesizes silence for pause_after_sec when building master audio.

3. Scene matching happens only inside beat.voice_in → beat.voice_out.
   - Never match scenes inside beat.pause_in → beat.pause_out.

4. Beat pause is a separate timeline item.
   - It is not a scene.
   - It is not inferred from gaps.

5. Silent scenes are supported as first-class visual timeline scenes.
   - They are not word-matched.
   - They are allocated into available gaps inside their beat.
```

---

# 1. Objective

Implement a robust two-level voice matching system:

```text
Level 1 — Beat timeline:
    Exact, based on measured per-beat audio duration.

Level 2 — Scene timeline:
    Matched locally within each beat window using Whisper word timestamps.
```

The system must output a production-ready intermediate timeline JSON for rendering and Kdenlive export.

---

# 2. Core Principle

```text
Voice is the master timeline for spoken content.
Beat boundaries are exact because each beat has its own audio file.
Scene boundaries are resolved only within their beat.
Global scene matching across the full audio is forbidden.
```

## 4.1 whisper_mode

Allowed values:

```text
master_audio
per_beat_audio
```

Recommended default:

```text
master_audio
```

## 4.2 timestamp_mode

Derived from whisper_mode:

```text
master_audio    → global timestamps
per_beat_audio  → local timestamps
```

Hard rule:

```text
If timestamp_mode = global:
    scene.voice_in = word.start
    scene.voice_out = word.end

If timestamp_mode = local:
    scene.voice_in = beat.voice_in + word.start
    scene.voice_out = beat.voice_in + word.end
```

Never mix both.

## 4.3 scene_silence_policy

Allowed values:

```text
allocate_existing_gap
inject_design_silence
```

Default:

```text
allocate_existing_gap
```

Meaning:

```text
allocate_existing_gap:
    Silent scenes only consume existing voice gaps inside the beat.

inject_design_silence:
    Renderer/audio assembler may insert additional silence for silent scenes.
    This changes the master audio timeline and should be used only if scene design wins over voice.
```

For this app, default should remain:

```text
voice_master + allocate_existing_gap
```

# 7. Processing Steps

## Step 1 — Load and validate inputs

Validation must check:

```text
- S6 JSON exists and is valid list/dict structure.
- Scene JSON exists and has scenes array.
- Every S6 scene reference exists in scene JSON.
- No duplicate scene reference unless allow_duplicate_scene_refs=true.
- Scene order in S6 matches scene order in scene JSON.
- Each beat has a valid beat_id.
- Each beat audio file exists after TTS/load stage.
```

Pseudo-code:

```python
def validate_s6_scene_refs(beats, scenes):
    scene_order = {s["id"]: i for i, s in enumerate(scenes)}
    scene_ids = set(scene_order)
    refs = []
    errors = []
    warnings = []

    for beat in beats:
        for sid in beat.get("scenes", []):
            refs.append(sid)
            if sid not in scene_ids:
                errors.append(f"Missing scene referenced by S6: {sid}")

    duplicates = sorted({sid for sid in refs if refs.count(sid) > 1})
    if duplicates:
        errors.append(f"Duplicate scene refs: {duplicates}")

    ref_positions = [scene_order[sid] for sid in refs if sid in scene_order]
    if ref_positions != sorted(ref_positions):
        errors.append("S6 scene references are not in scene JSON order.")

    return {
        "ok": not errors,
        "errors": errors,
        "warnings": warnings,
        "ref_count": len(refs),
        "scene_count": len(scenes)
    }
```

## Step 2 — Resolve visual sources

This must happen before timeline creation.

```python
def resolve_visual_source(scene: dict) -> tuple[str, str]:
    scene_id = scene["id"]
    visual_type_raw = scene.get("visual_type", "")
    visual_type = visual_type_raw.lower()

    if visual_type == "image":
        return "image", f"sources/{scene_id}.jpg"

    if visual_type in ("video", "slideshow"):
        return "video", f"sources/{scene_id}.mp4"

    # fallback
    return "unknown", f"sources/{scene_id}.mp4"
```

Rule:

```text
Image     → sources/{scene_id}.jpg
Video     → sources/{scene_id}.mp4
slideshow → sources/{scene_id}.mp4, pre-rendered and treated as video
```

## Step 3 — Generate or load per-beat TTS

Each beat produces one audio file:

```text
voice/beat-01.mp3
```

Rules:

```text
- TTS input is beat.narration_with_tags.
- Tags may influence voice style.
- [pause] and [long pause] may influence TTS internal pause.
- pause_after_sec is NOT included in TTS input by default.
```

If TTS system accidentally includes pause_after_sec, it must be disabled or config must be changed.

Default:

```text
pause_after_sec is generated later as synthetic silence.
```

Use ffprobe.

```python
def ffprobe_duration(path: str) -> float:
    ...
```

```python
beat["voice_duration"] = ffprobe_duration(beat["voice_file"])
```

```text
voice_duration must be > 0 for beats with voiced narration.
```

## Step 5 — Build exact beat timeline

Global cursor is used only here.

```python
cursor = 0.0

for beat in beats:
    dur = beat["voice_duration"]
    pause = float(beat.get("pause_after_sec") or 0.0)

    beat["voice_in"] = cursor
    beat["voice_out"] = cursor + dur

    beat["pause_in"] = beat["voice_out"]
    beat["pause_out"] = beat["pause_in"] + pause

    cursor = beat["pause_out"]

total_duration = cursor
```

Hard rule:

```text
Do not use global cursor for scene matching.
```

## Step 6 — Build master audio

Master audio must follow the beat timeline exactly.

```text
beat-01.mp3
+ generated_silence(pause_after_sec)
+ beat-02.mp3
+ generated_silence(pause_after_sec)
...
```

Recommended ffmpeg approach:

```text
Use concat demuxer/filter with explicit generated silence files or anullsrc segments.
Normalize sample rate and channel layout before concat.
```

Production requirements:

```text
- Output WAV recommended for editing stability.
- Use consistent sample rate, e.g. 48000 Hz.
- Use stereo or mono consistently.
- Avoid MP3 concat without re-encoding if timing accuracy matters.
```

Recommended output:

```text
outputs/master_voice.wav
```

Validation:

```text
abs(ffprobe_duration(master_voice.wav) - total_duration) <= 0.05s
```

# 8. Per-Beat Matching

## Step 8.1 — Get beat words

For global timestamps:

```python
def get_beat_words_global(whisper_words, beat, tol=0.05):
    return [
        w for w in whisper_words
        if beat["voice_in"] - tol <= w["start"]
        and w["end"] <= beat["voice_out"] + tol
    ]
```

Important:

```text
Do not include beat.pause_in → beat.pause_out.
```

## Step 8.2 — Classify scenes

```python
def classify_scene(scene):
    return "voiced" if scene.get("script", "").strip() else "silent"
```

Hard rule:

```text
A scene with script remains voiced even if matching fails.
```

## Step 8.3 — Single-scene beat shortcut

If a beat contains exactly one scene and that scene is voiced:

```python
scene.voice_in = beat.voice_in
scene.voice_out = beat.voice_out
scene.render_in = beat.voice_in
scene.render_out = beat.voice_out
scene.match_method = "single_scene_beat"
```

This is allowed because the whole beat narration belongs to one scene.

# 9. Production Deterministic Matcher

The matcher must be more robust than a fixed same-length window.

## 9.1 Normalization

```python
def normalize_text(text: str) -> list[str]:
    import re
    text = re.sub(r'\([^)]+\)', ' ', text)       # remove emotion tags
    text = re.sub(r'\[[^\]]+\]', ' ', text)       # remove [pause], [emphasis]
    text = text.replace("—", " ")
    text = text.replace("“", '"').replace("”", '"')
    text = text.lower()
    text = re.sub(r"[^a-z0-9'\s]", " ", text)
    text = re.sub(r"\s+", " ", text).strip()
    return text.split()
```

For Whisper words:

```python
def normalize_whisper_word(word: str) -> str:
    import re
    word = word.lower()
    word = re.sub(r"[^a-z0-9']", "", word)
    return word
```

## 9.2 Flexible window search

Use variable window length.

```python
min_len = max(1, int(len(scene_words) * 0.70))
max_len = max(min_len, int(len(scene_words) * 1.35))
```

This handles Whisper word split/merge and minor recognition differences.

## 9.3 Scoring

Use weighted score:

```text
start_anchor_score  = 25%
end_anchor_score    = 25%
full_window_score   = 35%
order_continuity    = 15%
```

Suggested:

```python
score = (
    0.25 * start_score +
    0.25 * end_score +
    0.35 * full_score +
    0.15 * continuity_score
)
```

## 9.4 Search window bounds

Search starts from local cursor, not from the whole beat if possible.

```text
cursor resets at the start of every beat.
cursor advances only after successful voiced scene match.
```

However, to avoid one bad match blocking the rest of the beat, allow bounded lookahead:

```python
search_start = max(0, cursor - 3)
search_end = len(beat_words)
```

## 9.5 Matcher output

```json
{
  "start_idx": 12,
  "end_idx": 34,
  "score": 0.91,
  "method": "within_beat_flexible_fuzzy"
}
```

## 9.6 No match handling

If no match:

```text
Do not mark silent.
Do not advance cursor.
Mark unmatched_voiced_scene.
Optionally run fallback.
```

# 10. Fallback Strategy

LLM fallback is emergency only, not normal path.

Trigger when:

```text
- deterministic score < threshold
- invalid word range
- scene order overlap
- no_match
```

LLM fallback input must be bounded:

```json
{
  "beat_id": "beat-04",
  "scene_id": "SCENE-12",
  "scene_script": "...",
  "candidate_words": [
    {"index": 0, "word": "..."},
    {"index": 1, "word": "..."}
  ],
  "neighbor_context": {
    "previous_scene_end_idx": 41,
    "next_scene_start_idx": null
  }
}
```

LLM fallback output must be word indices:

```json
{
  "scene_id": "SCENE-12",
  "start_word_index": 42,
  "end_word_index": 70,
  "confidence": 0.82
}
```

Validation before accepting:

```python
0 <= start_word_index <= end_word_index < len(beat_words)
confidence >= 0.70
no overlap with previous accepted scene
```

If invalid:

```text
Keep unmatched_voiced_scene.
Do not silently guess.
```

# 11. Silent Scene Allocation

Silent scenes are scenes with empty script.

They are not word-matched.

They are allocated only inside their beat.

## 11.1 Gap groups

Example:

```text
S01 voiced
S02 silent
S03 silent
S04 voiced
```

The silent block `[S02, S03]` is allocated into:

```text
S01.voice_out → S04.voice_in
```

## 11.2 Leading silent scenes

If silent scenes appear before the first voiced scene in beat:

```text
beat.voice_in → first_voiced.voice_in
```

## 11.3 Trailing silent scenes

If silent scenes appear after the last voiced scene in beat:

```text
last_voiced.voice_out → beat.voice_out
```

## 11.4 Only silent scenes in beat

If a beat has only silent scenes:

```text
Allocate across beat.voice_in → beat.voice_out.
```

If beat voice duration is zero:

```text
Use design duration and warn.
```

## 11.5 Allocation function

```python
def allocate_silent_gap(left_out, right_in, silent_scenes, beat_id):
    gap_start = left_out
    gap_end = right_in
    gap_duration = max(0.0, gap_end - gap_start)

    if not silent_scenes:
        return []

    design_total = sum(max(0.0, s.get("duration", 0.0)) for s in silent_scenes)

    if design_total <= 0:
        durations = [gap_duration / len(silent_scenes)] * len(silent_scenes)
    else:
        ratio = gap_duration / design_total
        durations = [
            max(0.0, s.get("duration", 0.0)) * ratio
            for s in silent_scenes
        ]

    cursor = gap_start
    out = []

    for scene, dur in zip(silent_scenes, durations):
        design_duration = max(0.0, scene.get("duration", 0.0))
        warnings = []

        scale_ratio = dur / design_duration if design_duration > 0 else None
        if scale_ratio is not None and scale_ratio < 0.50:
            warnings.append("silent_scene_compressed_too_much")
        if scale_ratio is not None and scale_ratio > 2.00:
            warnings.append("silent_scene_stretched_too_much")

        out.append({
            "type": "scene",
            "scene_id": scene["id"],
            "beat_id": beat_id,
            "scene_type": "silent",
            "render_in": cursor,
            "render_out": cursor + dur,
            "duration": dur,
            "voice_in": None,
            "voice_out": None,
            "design_duration": design_duration,
            "visual_type": scene.get("visual_type"),
            "visual_source": scene.get("visual_source"),
            "scale_ratio": scale_ratio,
            "match_method": "gap_allocated",
            "warnings": warnings
        })

        cursor += dur

    return out
```

# 12. Beat Pause Handling

`pause_after_sec` belongs to the beat.

It is not a scene.

It is represented as a timeline item.

```python
if beat["pause_after_sec"] > 0:
    timeline.append({
        "type": "beat_pause",
        "beat_id": beat["beat_id"],
        "after_scene_id": beat["scene_ids"][-1] if beat["scene_ids"] else None,
        "render_in": beat["pause_in"],
        "render_out": beat["pause_out"],
        "duration": beat["pause_after_sec"],
        "visual_policy": "freeze_tail",
        "audio_policy": "synthetic_silence_in_master_audio"
    })
```

Rules:

```text
- Beat pause is not used for scene matching.
- Beat pause is not allocated to silent scenes.
- Beat pause becomes freeze/transition/bumper in visual timeline.
```

# 13. Timeline Assembly Rules

For each beat, timeline items should cover:

```text
beat.voice_in → beat.voice_out     = scene items
beat.pause_in → beat.pause_out     = beat_pause item
```

Scene items inside the beat must be ordered by original scene order.

Beat pause item comes after all scene items in that beat.

# 14. Validation

## 14.1 Timestamp offset validation

If `timestamp_mode = global`, assert:

```python
for item in voiced_items:
    assert beat.voice_in - 0.1 <= item.voice_in <= beat.voice_out + 0.1
```

If any item is larger than expected by roughly `beat.voice_in`, suspect double offset.

Diagnostic warning:

```text
possible_double_timestamp_offset
```

## 14.2 Scene coverage validation

Within a beat:

```text
sum(scene item durations inside beat) ≈ beat.voice_duration
```

Tolerance:

```text
±0.05s or ±1 frame
```

Full beat block:

```text
sum(scene item durations) + beat_pause.duration
≈ beat.voice_duration + pause_after_sec
```

## 14.3 No voiced scene may become silent

```python
if scene.get("script", "").strip() and result["scene_type"] == "silent":
    raise ValueError("Voiced scene incorrectly marked as silent.")
```

## 14.4 No negative duration

```python
if item["render_out"] < item["render_in"]:
    raise ValueError("Negative timeline duration.")
```

## 14.5 No major overlap

```python
if cur["render_in"] < prev["render_out"] - 0.03:
    warn_or_error("timeline_overlap")
```

## 14.6 Unmatched scene policy

If `strict_no_match = true`:

```text
Fail pipeline if any voiced scene remains unmatched.
```

If `strict_no_match = false`:

```text
Emit timeline with unmatched item and diagnostics.
Do not render/export final project unless user allows fallback placement.
```

# 16. Acceptance Criteria

The sprint is complete when:

```text
1. Per-beat MP3 files are loaded or generated.
2. pause_after_sec is synthesized into master_voice.wav as silence.
3. Beat timeline is exact from ffprobe durations.
4. Master audio duration matches the beat timeline within tolerance.
5. Whisper is run once on master audio by default.
6. Scene matching uses local per-beat word windows only.
7. No global scene cursor is used.
8. Global timestamp mode does not add beat.voice_in twice.
9. Single-scene beats are assigned full beat voice window.
10. Multi-scene beats use robust flexible fuzzy matching.
11. Silent scenes are allocated into local beat gaps.
12. Beat pauses are explicit timeline items.
13. No voiced scene is ever converted to silent due to no_match.
14. Diagnostics identify unmatched scenes, overlaps, coverage gaps, and extreme scaling.
15. Output timeline JSON is ready for Kdenlive XML export.
```

---

# 17. Final Statement

```text
Use a production two-level alignment algorithm. Beat boundaries are exact because each beat has its own measured audio file. pause_after_sec is synthesized by the pipeline as silence in the master audio, not generated by TTS. Whisper timestamps are global when master audio is transcribed; therefore scene timestamps must not be offset again. Scene matching is local within each beat. Silent scenes are allocated into local gaps. Beat pauses are explicit timeline items. The output is a validated intermediate edit timeline suitable for Kdenlive export.
```
